# 폴리곤 러너

## 실행
1. Node.js 20 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

## GitHub + Render 배포
1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Render에서 **New + → Web Service**를 선택하고 GitHub 저장소를 연결합니다.
3. 설정은 `Build Command: npm install`, `Start Command: npm start` 입니다. `render.yaml`을 사용해도 됩니다.
4. 배포가 끝나면 Render가 제공하는 주소로 게임에 접속합니다.

## 게임 규칙
- 기본 캐릭터는 거북이이며 자동으로 다각형의 변을 따라 이동합니다.
- 한 바퀴를 완주할 때마다 해당 다각형의 보상 × 돈 배율만큼 코인을 얻습니다.
- 코인으로 토끼, 여우, 치타, 용을 구매하고 캐릭터 속도를 바꿀 수 있습니다.
- 삼각형부터 팔각형까지 코스를 구매할 수 있습니다.
- 배율 강화로 완주 보상을 늘릴 수 있습니다.
- 코인, 구매 항목, 선택 캐릭터, 선택 코스, 배율은 브라우저의 localStorage에 저장됩니다.
- 서버는 상태 확인 API와 상위 10개 완주 기록 랭킹을 제공합니다.

## 데이터 저장 주의
Render 무료 인스턴스의 로컬 파일은 재배포/재시작 시 초기화될 수 있습니다. 랭킹을 계속 보존하려면 Render의 Persistent Disk를 연결하고 `DATA_DIR`을 디스크 경로(예: `/var/data`)로 설정하거나 외부 데이터베이스를 연결하세요. 게임 진행 저장은 현재 브라우저에 저장되며 계정 간 동기화는 포함하지 않습니다.
